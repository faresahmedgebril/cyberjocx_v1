# CyberJocx Labs browser preview

A responsive, interactive front-end prototype for the CyberJocx training-labs concept.

## Open it
Once GitHub Pages deployment succeeds, open the project Pages URL shown in the repository's **Actions** / **Deployments** status.

## Included
- Dashboard, lab library cards, lab detail pages, and demo progress.
- Browser-only simulated terminal commands: `help`, `ip`, `nmap`, `curl`, and `clear`.
- Example private target IP `172.30.0.10`.

## Important limitation
This is a **front-end prototype**, not a live cyber range. Terminal output is simulated and the example IP is not a real target. Real Ubuntu/Docker machines require a backend host, per-session network isolation, resource limits, and a controlled remote access gateway. GitHub Pages hosts static web content and cannot run Docker containers.
